## 🚀 Особенности

### 🎯 Уникальные возможности
- **🔢 Настраиваемый размер поля** - от классического 3x3 до бесконечного поля
- **📏 Переменная длина выигрышной линии** - от 3 до любого значения
- **🤖 4 уровня сложности ИИ** - от новичка до эксперта
- **🎮 Гибкие настройки** - выбор первого хода, сохранение прогресса

### 🎨 Визуальные элементы
- **✨ Плавное масштабирование и панорамирование** колесом мыши
- **🏆 Анимированные победные линии** с подсветкой
- **📊 История ходов** в реальном времени
- **🎯 Подсветка выбранной клетки**
- **💾 Визуальные уведомления** о сохранении игры

### ⚡ Умный искусственный интеллект
- **🎲 Easy** - случайные ходы вокруг ваших фигур
- **🎯 Medium** - базовые стратегии и блокировки
- **🔥 Hard** - продвинутые эвристики и оценка позиций
- **🧠 Expert** - алгоритм минимакс с альфа-бета отсечением

## 📥 Установка

### Windows
```bash
# Требуется Visual Studio 2019+
1. Откройте файл .sln в корневой директории
2. Соберите и запустите проект
```

### Linux (Xubuntu/Debian)
```bash
# Установите зависимости
sudo apt update
sudo apt install make gcc libgl1-mesa-dev libglfw3-dev

# Сборка и запуск
make
./krestiki-noliki
```

## 🎮 Управление

### Основное управление
| Действие | Клавиша |
|----------|---------|
| Перемещение курсора | `WASD` или `Стрелки` |
| Сделать ход | `Пробел` |
| Центрировать вид | `Shift` |
| Сохранить игру | `Alt + Q` |
| Показать справку | `H` |
| История ходов | `M` |
| Выход в меню | `ESC` |

### Управление мышью
- **ЛКМ + перемещение** - панорамирование поля
- **Колесо мыши** - масштабирование
- **Клик по кнопкам** - навигация в меню

## 🛠 Настройки игры

### Уровни сложности
- **Easy** - ИИ делает случайные ходы
- **Medium** - базовые стратегии защиты
- **Hard** - продвинутые тактики
- **Expert** - непобедимый алгоритм

### Параметры поля
- **Размер поля**: 3x3, 5x5, 7x7... или бесконечное
- **Длина линии**: от 3 символов и более
- **Первый ход**: игрок или компьютер

## 🏆 Особенности реализации

### 🔧 Технические детали
- **Язык**: Чистый C с использованием GLFW для графики
- **Алгоритмы**: Минимакс с альфа-бета отсечением для экспертного ИИ
- **Оптимизация**: Локальная проверка условий победы
- **Память**: Динамическое управление ресурсами

### 🎯 Бенчмаркинг
Встроенная система тестирования производительности:
```bash
# Запуск тестов производительности
Нажмите 1-5 в главном меню для запуска бенчмарков
Нажмите 'T' для запуска бенчмарка WinCond
```
